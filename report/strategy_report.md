# 海外运动健康垂类 KOL 营销效果与预算分配策略报告

**数据源**：Kaggle「Social Media Engagement Dataset」— 5,000 条社媒帖，覆盖 12 个内容垂类、6 个平台（Instagram / TikTok / YouTube / Facebook / Twitter / LinkedIn），含互动率、播放、粉丝量、达人层级、内容形式等字段。
**分析范围**：运动健康垂类（Sports 401 帖 + Fitness 393 帖 + Health 397 帖 = **1,191 帖**）。
**分析链路**：Python 数据清洗与指标计算 → SQLite 多维查询（9 个业务查询，含窗口函数分层）→ Plotly 交互式决策看板 → 纯佣制 ROI 情景模型。

---

## 一、执行摘要（3 条核心结论）

1. **TikTok 是运动健康垂类的效率断层第一平台**：平均互动率 22.96%，是第二名 YouTube（11.15%）的 2 倍、Instagram（6.51%）的 3.5 倍；Top10 互动榜全部来自 TikTok。
2. **小体量达人的互动效率远高于头部**：Micro 达人平均互动率 32.5%、Mid-tier 11.5%，而 Macro 仅 3.4%；互动型内容形式（Duet 28.4% / Stitch 20.5% / Video 10.7%）显著优于图文与长文本。
3. **预算分配建议**：$100K 预算中 **51% 押注 TikTok**（Macro 做供给量、Micro/Mid 做效率测试），28% 给 Instagram（侧重 Micro），其余分散测试；在佣金制下 ROI 比率由佣金率锁定，真正的决策变量是**每千美元投入的 GMV 产出效率**。

---

## 二、数据与方法说明

### 2.1 数据源
- **唯一数据源**：Social Media Engagement Dataset（Kaggle）。互动指标分布真实：播放量 527~999K，互动率 0.05%~3510%，方差充足。
- 数据质量说明：分析前曾评估另一候选数据集（52,214 条），其互动指标近乎恒定（播放量集中于 9,676~10,551、点赞集中于 1,354~1,668），疑为合成数据，故排除；全部分析仅基于上述一个数据源。

### 2.2 指标口径
- **互动率（Engagement Rate）**：数据集自带字段；用于均值比较时按 99 分位封顶（168.0%）以抑制极端值影响。
- **每千次播放互动量**：`(点赞+评论+转发+收藏) / 播放量 × 1000`。
- **佣金制 ROI**：`ROI = GMV ÷ 佣金支出`；当佣金率固定为 r 时，`ROI = 1/r`（公式恒等）。

### 2.3 情景模型假设（全部显式标注，可调整）
| 参数 | 取值 | 说明 |
|---|---|---|
| CPM | $8 / 千次播放 | 达人内容分发成本假设 |
| 基础 CVR | 1.5% | 播放→购买转化基准 |
| CVR 缩放 | 随互动率线性缩放 | 高互动内容转化率更高（营销常识假设） |
| AOV | $60 | 平均客单价 |
| 佣金率 | 20% | 佣金制 KOL 合作 |
| 总预算 | $100,000 | 模拟金额 |

## 三、核心发现（基于 SQL 分析）

### 3.1 平台对比：TikTok 断层领先
| 平台 | 帖数 | 平均互动率 | 中位播放 |
|---|---|---|---|
| **TikTok** | 187 | **22.96%** | 241,149 |
| YouTube | 105 | 11.15% | 510,240 |
| Instagram | 305 | 6.51% | 23,608 |
| Facebook | 244 | 4.86% | 39,007 |
| Twitter | 247 | 3.97% | 47,775 |
| LinkedIn | 103 | 1.01% | 13,565 |

> TikTok 在运动健康垂类的互动效率远超其他平台；YouTube 虽有最高中位播放，但互动率仅为 TikTok 的一半。

### 3.2 达人层级：体量越小，互动效率越高
| 层级 | 帖数 | 平均互动率 | 中位粉丝 |
|---|---|---|---|
| Nano（n=18，样本小慎读） | 18 | 101.8% | 5,919 |
| Micro | 102 | **32.5%** | 28,827 |
| Mid-tier | 111 | 11.5% | 76,262 |
| Macro | 960 | 3.4% | 304,189 |

> 与行业基准方向一致：头部达人（Macro）互动率显著低于腰尾部达人。

### 3.3 内容形式：互动型内容碾压图文
Top5 高互动形式：**Duet（28.4%）> Stitch（20.5%）> Community Post（11.9%）> Video（10.7%）> Short（9.9%）**；图文类（Photo 6.2%、Carousel 5.0%、Post 4.9%）和长文本（Article 1.6%、Document 0.8%）明显落后。

### 3.4 垂类定位：运动健康处于中游，但内容粘性不弱
- 平均互动率 8.16%，低于全量其他垂类的 8.99%（Travel 10.5%、Tech 10.4% 领先）；
- 但**每千次播放互动量 315.4，高于其他垂类的 308.3**——垂直内容受众精准、单次触达质量高，属于「量不大但转化质量好」的垂类。

### 3.5 发布时间：周日晚/周一发，周三最弱
周日（9.73%）与周一（9.56%）平均互动率最高，周三（6.17%）最低。

## 四、预算分配建议（$100K）

基于「每千美元 GMV 效率 × 达人池供给量」加权模型，建议分配如下（明细见 `sql_results/scenario_model.csv`）：

| 段位 | 建议分配 | 占比 | 策略定位 |
|---|---|---|---|
| TikTok × Macro | $22,479 | 22% | 供给充足，做基本盘放量 |
| TikTok × Micro | $21,013 | 21% | 效率最高（每千美元 GMV 约 $57.2万），先小预算验证再放量 |
| Instagram × Micro | $8,259 | 8% | 第二效率平台的中小达人测试 |
| TikTok × Mid-tier | $7,784 | 8% | 效率次优，做腰部补充 |
| 其余平台×层级 | $40,465 | 41% | 分散测试（YouTube Macro、Twitter Micro 等） |
| LinkedIn | ~$887 | <1% | 建议基本不投 |

**执行建议**：
1. 首期用 30% 预算（约 $30K）跑 TikTok Micro/Mid 的 A/B 测试，验证实际转化后放量；
2. 内容策略优先 Duet / Stitch / Video 形式，发布安排在周日晚至周一；
3. 佣金制下 ROI 比率固定，**重点应放在「佣金率」与「达人质量筛选」**，而非投放渠道；
4. 预算分配为模型输出，落地前需用 2-4 周小样验证 CVR 与 AOV 假设（敏感性表见 `sql_results/scenario_sensitivity.csv`）。

## 五、行业基准交叉验证

| 本项目发现 | 行业基准（StarNgage 健身垂类创作者数据） | 一致性 |
|---|---|---|
| Macro 达人平均互动率 3.4% | 头部/巨型创作者基于播放的互动率约 1.5%-3% | ✅ 量级一致 |
| 中小体量达人互动率明显更高 | 腰中部创作者（10万-50万粉）基于播放互动率约 2%-4% | ✅ 方向一致（绝对值的口径差异见局限性） |
| 互动型/转变型内容效率最高 | 健身「转变类」内容互动率 8%-15%，为垂类内最高 | ✅ 方向一致 |
| 垂类越垂直、受众越精准，互动质量越高 | 精准垂类创作者显著优于泛内容账号 | ✅ 方向一致 |

> 基准来源：StarNgage Fitness Creator Engagement Benchmarks（印尼 / 马来西亚市场报告）。

## 六、局限性与声明

1. 数据为公开数据集，无真实投放成本与销售额，ROI 与预算分配为**透明假设下的情景模拟**，只用于相对比较，不构成绝对预测；
2. Engagement Rate 为数据集自带口径（未披露为基于播放还是基于粉丝），与行业基准可能存在定义差异，交叉验证仅判断方向一致性；
3. 各平台、各层级的样本量不均衡（Macro 占 80%），Nano 层级样本仅 18 帖，结论需谨慎外推；
4. 数据时间跨度为 2024-2025 年，平台算法与政策变化可能影响结论时效性。
